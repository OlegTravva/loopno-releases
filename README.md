# LOOPNO

[Скачать установщик Windows x64](https://github.com/OlegTravva/loopno-releases/releases/latest)

Музыкальный стриминг LOOPNO. В этом репозитории публикуются установщики, файлы обновлений и исходный код;

## Установка

Закройте прежнюю ZIP-версию и один раз установите LOOPNO через файл `LOOPNO-Setup-<версия>.exe` из последнего выпуска. Аккаунт и настройки подтянутся сами.

После появления следующих выпусков приложение покажет плашку обновления. Нажмите «Обновить», дождитесь загрузки, затем выберите «Перезапустить и установить».
