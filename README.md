# LOOPNO

[Скачать установщик Windows x64](https://github.com/OlegTravva/loopno-releases/releases/latest)

Музыкальное приложение LOOPNO. В этом репозитории публикуются установщики и файлы обновлений; исходный код приложения здесь не размещается.

## Установка

Закройте прежнюю ZIP-версию и один раз установите LOOPNO через файл `LOOPNO-Setup-<версия>.exe` из последнего выпуска. Аккаунт и настройки используют прежний каталог данных.

После появления следующих выпусков приложение покажет плашку обновления. Нажмите «Обновить», дождитесь загрузки, затем выберите «Перезапустить и установить».

Текущая бета-сборка без цифровой подписи издателя: Windows может показать предупреждение при первом запуске установщика. Доступность загрузки зависит от сети пользователя.
